# 视觉系统与横版构图

## 配色与风格

| 角色 | 色值 | 用法 |
|---|---|---|
| 主背景：深海军蓝 | #0B1526 | 深度、未知、严肃 |
| 次背景：炭黑 | #111827 | 信息承载、稳定层次 |
| 主要文字：暖白 | #F5F3EE | 深底正文 |
| 重点：香槟金 | #E6BC69 | 原则、价值、机会 |
| 科技：青蓝 | #46B9E8 | 技术、理性、连接 |
| 风险：暗红 | #C65B58 | 风险与错误，配文字/符号 |
| 积极结果：柔绿 | #67B99A | 已达成、改善，配文字/符号 |

深色为默认基调，允许浅底解释页形成明暗节奏；浅底改用深色文字，不能机械套用暖白。颜色之外用文字、形状或图标辅助区分，确保脱离色彩仍能理解。

电影写实采用真实材质、空间深度、侧光/逆光、柔和体积光和克制的金色光源。避免全画面发光、过度霓虹、塑料人物和无关机器人。用户偏爱手绘参考时，可统一采用成熟编辑插画与纸张质感；不要在同一套中随机混搭写实人物与卡通机器人。

## 16:9 构图候选

- 故事：左侧约 40% 为安静文字区，右侧环境和人物承载冲突；也可镜像。
- 观点：物体特写偏置，大留白承载一句结论；用尺度或材质变化形成张力。
- 知识：横向节点、因果链、分层结构或循环；局部插画提供语境，不遮住连线。
- 对比：相同尺度、相同维度的两栏；注明条件，避免用光影暗示没有依据的优劣。
- 行动：从左到右的路径、时间轴或递进节点，清楚标记顺序与产物。
- 总结：中心概念与有限分支，或主框架加关系箭头；不重新塞入全部细节。

相邻页面优先改变镜头距离、主体位置或信息组织；允许章节母版重复。避免反复“中央背影＋远方岔路”。人物不是必需元素。大背景先留出干净文字区，复杂区域使用实色或足够不透明的承载层。

## 隐喻选择

| 概念 | 可用物象 | 使用边界 |
|---|---|---|
| 风险控制 | 护栏、安全绳、盾牌 | 降低风险不等于保证安全 |
| 第二曲线 | 桥梁、第二座山峰、双支点 | 保留探索成本与条件 |
| 长期主义 | 树木、马拉松、灯塔 | 不能暗示坚持必然成功 |
| 独立思考 | 指南针、观察台 | 不能把独立等同于否定他人 |
| AI 协作 | 驾驶员与导航、工作台 | 人有判断责任，系统有能力边界 |
| 知识积累 | 建设中的城市、书架连接 | 表达组织关系而非仅堆数量 |
| 能力退化 | 闲置工具、减少的练习痕迹 | 需与原稿论证条件一致 |
| 复利 | 生长、滚雪球、阶梯 | 真实收益不能用象征曲线冒充 |
| 机会成本 | 天平、沙漏、资源分配 | 展示放弃的选择与有限资源 |
| 反脆弱 | 经反馈调整的结构 | 风暴后仍完好仅说明抗冲击，不能自动证明反脆弱 |

先写出“视觉元素→概念→关系”，对应不成立时换结构图。

## 字体、密度与尺寸

最多四级文字：标题、副标题、2—4 个要点、辅助标注。故事页约 15—40 个汉字，观点页约 10—30 字，知识页约 30—100 字；总结依结构调整。它们是参考值，信息过多优先拆页而非缩字。

标准宽屏 PPT 可使用 13.333×7.5 英寸。PPT 字号用 pt：标题 44—64、副标题 26—36、正文 24—30、标注 18—22；依实际画布和观看距离调整。1920×1080 是导出像素，不是 PPT 字号单位；转为 HTML/SVG 时按实际渲染比例换算，不能直接把 pt 数值当 px。

优先思源黑体、Noto Sans CJK SC、苹方等环境实际可用字体。记录选用字体与回退，渲染检查中文缺字和字体替换。主标题可用适量展示字体，正文保持清晰。

安全边距按每边约 5%—8% 预留。若用户指定竖屏，重新分镜并依据平台预览确认字幕、头像和操作按钮避让区；未知平台先预留更宽区域并标明假设。
