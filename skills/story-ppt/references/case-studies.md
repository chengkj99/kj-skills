# 七张用户参考图的设计转译

这些记录来自用户提供的 V1.0 指南及七张图片的视觉观察。图片是设计参考，不是事实证据；本 skill 不依赖原电脑的桌面路径。原图未打包分发；若要求精确复现人物或材质，应读取用户本次提供的图片。以下文字足以指导结构转译。

| 案例 | 可提取的视觉方法 | 默认 16:9 转译 | 内容与风格边界 |
|---|---|---|---|
| 穿越牛熊的风险控制之路 | 前景投资者、悬崖与护栏、冷暗风险区对照暖金前路、盾牌和分散配置 | 拆为“先管理风险”的观点页、“失去保护”的故事页、“控制风险的方法”的解释页 | 图中配置圆环没有数据就只作类别示意，不编造比例；避免把风险控制画成必然盈利 |
| 福格行为模型：行为发生的原理 | 三个输入汇聚中央结果；下方用跑步情境落地 | 横向三要素关系图一页，具体情境另页 | 图片中的乘号表达须核实；不能把助记关系当成可量化算式，也不能把跑步时长当作普遍处方 |
| 冷静思考，智选未来 | 左右对照、幻觉提示、多来源汇聚、底部结果 | 决策情境、AI 辅助边界、核验行动分别成页 | 原图具体模型版本及能力描述不直接沿用；多模型一致不等于真实，需要独立来源或实测 |
| 无为而治：AI驾驭三层图 | 人→工作系统→AI 的分层，外侧反馈箭头形成闭环 | 改为横向三段或横版三层系统图，反馈回到负责人 | 手绘属于可选风格；图中层次用于概念解释，不冒充某产品的真实架构 |
| 应对职业危机：一端保底，一端进攻 | 风暴为压力背景，人物连接主业与探索两端，杠铃解释资源配置 | “双端策略”场景页＋“两端如何行动”路径页 | 风暴情绪降到合适强度；不暗示副业必胜或单一职业必然失败 |
| 重大决定，别急着下结论 | 开场困境→咨询对比→验证步骤→个人判断，具有完整纵向叙事 | 拆成困境故事、对比条件、核验路径、观点结尾 | 保留人的最终判断；避免制造“问人无用、AI 全知”的假二分 |
| Harness：AI Agent 的工程中枢 | 工作现场隐喻、六类支撑组件、旁侧执行流程、纸面图与深背景 | 概念隐喻页、组件框架页、执行流程页；按原稿确定需要几页 | 保留组件与流程区别；连线必须有明确含义，不把示意目录视为真实工程文件 |

共同方法是：强主张、具体物象、空间关系、有限色彩语义、局部知识结构和明确收束。海报中的密集小字、强霓虹、巨型艺术字和全部模块并列，不必迁移到演讲屏幕。

示例：把“重大决定”长图改为四页时，前三页分别回答“面对什么困境”“参考意见有哪些边界”“如何查证”，最后一页回答“谁承担选择”。每页保留一句可独立理解的观点；讲述细节放备注，不能只留下无上下文金句。
