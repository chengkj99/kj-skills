# 断言台账与置信度标尺

处理任何含数字的材料前读这一份。核心理由：**不登记就等于默认可信**。数字一旦进入你的整理稿而没有标注状态，几周后你就分不清它是查过的还是听来的了——这是引用事故最常见的来源。

## 台账字段

| 字段 | 作用 | 填写要求 |
|---|---|---|
| 断言 | 归一化后的主张 | 一句话，保留原始量级和单位 |
| 原话位置 | 回查锚点 | 时间戳、段落号或可搜索的短语 |
| 口径是否明确 | 判断这个数字能否被解释 | 明确/不明确，不明确的写出缺哪个口径 |
| 可核实性 | 判断值不值得去查 | 可查（写出查什么）/ 难查（写出为什么） |
| 置信度 | 引用许可等级 | A / B / C / D，见下 |
| 待查 | 行动标记 | 是 / 否 |

示例：

| 断言 | 原话位置 | 口径是否明确 | 可核实性 | 置信度 | 待查 |
|---|---|---|---|---|---|
| 某行业平均利润 3% | 01:55 | 否（整车还是含零部件？国内还是全球？） | 可查行业协会年报 | B | 是 |
| 某平台全职从业者 300 万人 | 26:20 | 否（「全职」如何定义） | 难，平台不公开 | C | 否 |
| 某产品年营收 1000 亿 | 1:05:20 | 否 | 可查第三方估算 | D（与公开估算差约一个量级） | 是 |
| 某公司被挂牌出售 | 1:12:40 | 是 | 公开事件，已核 | A | 否 |

## 置信度标尺

- **A**——有独立公开来源，且**我已核实**。只有这一级可以直接对外引用。
- **B**——量级或方向可信，但口径不明。引用时必须同时写出口径不明。
- **C**——单一来源口述，无法核实。**口述数字默认落在这里。** 只能作为「某人的说法」转述。
- **D**——存在内部矛盾，或与已知事实冲突。只能作为「该说法存疑」提及，并写出冲突点。

判定 A 级需要真的去查过。**没有联网或没有查证时，最高只能给 B**，并在报告里写明「未核实」。

## 标注纪律

1. **未核实就写「未核实」。** 绝不为一个数字补上看起来合理的来源、机构名或年份。这是本 Skill 最重要的一条纪律：编造来源比引用错数字的危害大得多，因为它让错误变得不可追查。
2. **不确定的宁可留空**，不要填猜测值。空白是诚实的信息，猜测值是污染。
3. **保留原始量级和单位**，不做换算美化。讲者说「一个亿」就记「一个亿」，不要改写成「100,000,000」制造精确感。
4. **区分「讲者说的数字」和「我算出来的数字」。** 由讲者数字推导出的结果（比如两个数相除得到的倍数）要标明是推导值，因为它继承了原始数字的全部不确定性。
5. **同一个数字在材料里出现多次且不一致时，全部记下来**，不要挑一个用。前后不一致本身就是重要发现。

## 常见的口径缺失清单

数字标注为「口径不明」时，通常缺的是下面某一项。逐项核对能快速定位问题：

- **范围**：全行业还是头部？全国还是某地区？含子类还是仅主类？
- **时间**：哪一年？年度还是滚动 12 个月？某个特殊时期？
- **统计方式**：均值还是中位数？加权还是算术？含税还是不含税？
- **主体**：整体还是单一环节？集团还是单一业务线？
- **口径来源**：官方统计、行业协会、第三方估算，还是企业自述？

均值与中位数的差别在利润率、收入、时长这类长尾分布上尤其致命——只给「平均」的数字往往掩盖了绝大多数样本的真实状况。

## 需要额外警惕的数字形态

- **恰好取上限的数字**：「退货率 80%」「转化率 30%」这类整数上限，常常是某个极端品类或某次活动的值被当成常态。
- **量级过于漂亮的数字**：「1000 亿」「10 万倍」「1000 年产能」。这类数字修辞功能强于信息功能，通常是为了震撼而取的近似值。
- **跨品类的倍数对比**：把两个不可比的单位放在一起相除（比如把时长差几十倍的两种内容按「部数」对比产能）。算术可能自洽，但结论无意义。遇到这种要在报告里明确写「这是修辞性对比，不是同口径对比」。
- **无法被观察到的总量**：「全国有 X 万人在做某事」这类数字通常没有权威统计源，属于 C 级。
- **讲者自身的绩效数字**：一手信息，但存在自我呈现偏差，且往往用了对自己有利的指标（比如用产出的绝对量而不是质量或返工率）。记录时把指标本身的合理性也标出来。
