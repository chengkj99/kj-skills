# 按材料类型调整重点

同一套流程用在不同材料上，价值集中的位置不一样。先判断类型，再决定把时间花在哪一步。

## 类型速查

| 类型 | 价值最高的部分 | 最大风险 | 特有动作 |
|---|---|---|---|
| 单人分享 / 演讲 / 课程 | 框架和方法论 | 话术成分高：选择性举例、金句不可证伪、数字取上限 | 四把刀全用；金句单列并逐条测可证伪性 |
| 双人 / 多人对话 | **分歧点和被追问处** | 表面共识掩盖真实差异 | 做观点矩阵；标注被追问后改口或含糊的地方 |
| 访谈 | 受访者的一手经验和具体细节 | 受访者的推论被当结论 | 严格切分「他做过的」和「他认为的」 |
| 内部会议 | 决策、责任人、时间点、约束条件 | 意见和决议混淆 | 先抽硬信息，再处理软信息 |
| 播客 / 闲聊 | 偶发的真实细节 | 信息密度低，容易过度加工 | 一般只做轻读 |

## 单人分享 / 演讲 / 课程

讲者通常在推销某个框架、某本书或某项服务，这不是缺陷，但要据此调整折扣率。

- **金句单独成表**，逐条问「什么能推翻它」。答不出的标为「传播用语，非分析工具」。
- 讲者会为了讲清楚而**把多因素压成单因素**，替代解释这一步不能省。
- 数字往往取有利上限且不标口径，全部默认 C 级。
- 留意**同一场内部的自相矛盾**——独白没有人打断，所以矛盾出现的概率反而更高，而按论证重排就能把它们并置。

## 双人 / 多人对话

价值不在双方都同意的地方，而在**分歧点**和**被追问后的反应**。追问是天然的压力测试，别浪费。

观点矩阵格式：

| 议题 | 发言人 A 立场 | A 的依据 | 发言人 B 立场 | B 的依据 | 是否收敛 |
|---|---|---|---|---|---|
| … | … | 一手经验 / 转述 / 推论 | … | … | 收敛 / 各持 / 未展开 |

额外标注三种信号：

- **被追问后改口**——原立场可能不牢。
- **被追问后含糊或转移话题**——薄弱处，值得单独列为开放问题。
- **双方用同一个词指不同的事**——常见的伪分歧或伪共识来源，要在报告里点明。

## 访谈

受访者的**一手经验**是全场最值钱的部分：他做过什么、遇到什么、当时怎么决定的。而他对行业趋势、他人动机、普遍规律的**推论**，其可信度不高于任何普通观点。

- 在观察层就用标记区分：`亲历` / `转述` / `推论`。
- 具体细节（时间、数字、当时的约束）优先保留，因为这些无法被泛化替代。
- 受访者说「大家都是这样」时，追问范围——这几乎总是从个人样本外推的。

## 内部会议

先抽硬信息，它们的性质和意见完全不同：

- **决议**：定了什么，谁负责，什么时间点，验收标准是什么。
- **约束**：预算、人力、依赖、不可变的截止日期。
- **未决**：明确悬置的事项，以及悬置的原因。

再处理软信息（意见、担忧、倾向）。**不要把「有人提议」写成「已决定」**，也不要把「未讨论」写成「无异议」。会议记录里最常见的失真就是这两种。

如果材料里没有明确的决议，如实写「本次未形成决议」，不要从讨论倾向里推断出一个结论。

## 播客 / 闲聊

信息密度通常不足以支撑标准级流程。默认轻读：捞出几个具体细节或反常识片段，产出自检问题即可。

只有当其中包含可复用的方法或密集的一手经验时才升级为标准级。判断依据仍然是「会不会影响我的决策或被我引用」。

## 混合型材料

「分享 + 问答」「主讲 + 圆桌」这类混合材料很常见。处理方式：**按段落分型，分别适用对应重点**，不要用一套标准贯穿全场。

问答环节通常比主讲部分更有价值——因为提问者构成了追问机制，而主讲人的即时回答没有经过预先包装。分析时不要因为问答段落短就跳过它。
