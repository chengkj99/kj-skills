# 证据与适用边界

本技能由 2026-10-12 的阅读表达形式调研转译。研究支持若干组成方法，没有研究证明本技能的完整组合对所有书和读者最佳。经典证据用于教学设计；工具能力和当前事实需要按需复核。

| 依据 | 对本技能的影响 | 结论边界 |
|---|---|---|
| [IES 学习实践指南，2007](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 图文结合、抽象与具体联系、示范与练习、间隔学习 | 各建议证据强度不同；不证明固定格式或 1/7/30 天最优 |
| [Fiorella 与 Mayer，多媒体学习设计，2021](https://doi.org/10.1017/9781108894333.019) | 删除无关信息、突出关键结构、说明与图邻近 | 冗余原则不能机械推广成删除所有字幕或文本 |
| [Karpicke 与 Blunt，2011](https://pubmed.ncbi.nlm.nih.gov/21252317/) | 看过后闭卷提取，检验理解与推理 | 科学文本实验；不能据此否定一切概念图 |
| [Pashler 等，学习风格综述，2008](https://www.psychologicalscience.org/journals/pspi/j.1539-6053.2009.01038.x/) | 依据任务与实际效果选择形式 | 不支持按视觉型等标签匹配教学；仍需尊重偏好和无障碍需求 |
| [Clinton-Lisell，听读元分析，2023](https://commons.und.edu/ehb-fac/75/) | 音频按场景使用 | 自主控制阅读速度时，边听边读未见可靠收益；不代表所有纯听或播客无效 |
| [Höffler 与 Leutner，动画元分析，2007](https://fis.leuphana.de/en/publications/instructional-animation-versus-static-pictures-a-meta-analysis/) | 动作、变化过程可考虑动画 | 效果依赖任务，不能推出任意文字改视频更好 |
| [PhET 研究实践](https://phet.colorado.edu/zh_TW/research) | 交互配合预测、观察与解释任务 | 科学模拟实践不直接证明哲学或文学阅读收益 |

当前项目中的完整调研位于 `reading/guides/reading-representation-best-practices-2026-10-12.md`；该文件是可选背景，本技能复制到其他工作区后仍可独立使用。
